# Java Calculator (BlueJ)

A simple console-based calculator built in Java using BlueJ.  
-addition
-subtraction
-multiplication
-division.

## Features
- ✅ Add (`+`)
- ✅ Subtract (`-`)
- ✅ Multiply (`*`)
- ✅ Divide (`/`)
- Handles divide-by-zero errors
- Uses `double` for decimal calculations

## How to Run (BlueJ)
1. Open **BlueJ**
2. Create/Open the project folder
3. Open `Calculator.java`
4. Click **Compile**
5. Right-click the `Calculator` class → **main** → OK
6. Follow the prompts in the terminal

## Example
Input:
- First number: `10`
- Operator: `*`
- Second number: `5`

Output:
- Result: `50.0`
